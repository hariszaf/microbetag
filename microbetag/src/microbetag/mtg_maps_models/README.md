# Reference data used by microbetag

* **kegg_mappings:** KEGG modules, their definitions, maps and descriptions, and the KEGG to ModelSEED compound
  mappings used for pathway and seed complementarities. The scripts that rebuild them are in the same folder.
* **MetaNetX:** compound cross-references, to map BiGG compounds (CarveMe, gapseq models) to ModelSEED.

The phenotrex models and FAPROTAX moved to the [microbetag-nf](https://github.com/msysbio/microbetag-nf)
pipeline, which runs those tools.
